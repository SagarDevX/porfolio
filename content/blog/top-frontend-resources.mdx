### Frontend is all about visuals.

When we open a website, we don't think about everything behind the scenes. We just see a page having text, buttons, images, animations & interactions.

All those little pieces have to work together.

That's where frontend development comes in.

Frontend is the part of a website that we see & interact with.

It isn't just about writing HTML, CSS or JS, but it's about how something should look, how it behaves, how it feels, and how it responds to interaction.

You can find many courses, tutorials, documentation, and YouTube channels for everything.

But I would suggest some resources to learn the fundamentals to build great interfaces.



<h1 className="mt-16 ">〇  HTML and CSS</h1>

<h2 className="mt-0 "> HTML</h2>

HTML stands for HyperText Markup Language.

HTML is the structure. It is used to describe the structure and meaning of content on a web page.

To learn HTML, [MDN HTML docs](https://developer.mozilla.org/en-US/docs/Web/HTML) is enough.

Focus on:
<ul>
  <li>Elements / Tags</li>
  <li>Attributes</li>
  <li>DOM</li>
  <li>Semantic HTML</li>
  <li>Forms</li>
  <li>Heading & Hierarchy</li>
  <li>Link & Buttons</li>
  <li>class and id</li> 
</ul>

## CSS

CSS stands for Cascading Style Sheets.

It is a language used to manipulate the visuals & layout of a website. It determines how a page's content looks.

The YT video helps me understand the fundamentals - [Learn CSS](https://www.youtube.com/watch?v=wRNinF7YQqQ)

<p>Things to focus on:</p>

<ul>
  <li>Flexbox</li>
  <li>Grid</li>
  <li>Position</li>
  <li>Spacing — margin, padding, gap</li>
  <li>Typography</li>
  <li>Color</li>
  <li>Borders and Shadows</li>
  <li>Responsive Design</li> 
</ul>

<h1 className="mt-16 ">〇 React JS</h1>


React JS is a JavaScript library for building user interfaces.

It is a JS library for building reusable pieces called components.

It breaks the interface into smaller reusable pieces called components. This makes large interfaces easier to maintain.

While searching for resources, I found a YouTube video that explains everything so easily - [React course for free](https://www.youtube.com/watch?v=CgkZ7MvWUAA)

Things to focus on:

<ul>
  <li>Components</li>   

  <li>Props</li>  

  <li>State</li>

  <li>Events</li>  

  <li>Conditional Rendering </li>  

  <li>Hooks & Effects</li>   


  <li>Data Flow</li>  
  
</ul>

<h1 className="mt-18">Don't Just Learn -  Build.</h1>
Learning web development isn't about finishing a course and suddenly knowing everything.


####  Courses can give you the foundation, but projects are where you actually learn. 


Don't just watch tutorials. Build things. Break things. Fix them. Try to recreate websites you like. Experiment with new ideas and technologies.

You don't need to know everything before starting a project.

### Learn → Build → Get stuck → Search → Fix → Repeat.



Keep practicing. Keep learning. And most importantly, keep building.

Every project you make will teach you something the next tutorial can't.
